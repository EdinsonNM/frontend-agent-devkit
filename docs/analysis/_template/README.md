# Analysis Template

Resultado persistente del comando `/analyze` (skill `frontend-analyze`).

Un directorio por area analizada: `docs/analysis/<area>/`.

Las specs de features sobre esa area referencian estos documentos
desde `specs/<feature>/02-current-state.md` en lugar de duplicar.

Mantenimiento: si el area cambia mucho, re-ejecutar `/analyze` para actualizar.
